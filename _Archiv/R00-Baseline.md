## ⚖️ Три тотожності, з яких випливає все

**1. Тяга береться тільки з імпульсу:**
```
T = ṁ(V_вих − V_польоту) + (p_вих − p_атм)·A_вих
```
Тиску всередині каналу в цьому рівнянні немає.

**2. Ефективність обернена до швидкості струменя:**
```
T/P = 2/V_вих   (точна тотожність для статичної тяги)
```
Швидкий струмінь = мала тяга на ват. Це причина, чому гелікоптер і турбовентиляторний двигун існують обидва.

**3. Потужність висіння визначається площею, а не тиском:**
```
P_ідеал = T^1,5 / √(2ρA)   →   P ∝ 1/√A ∝ 1/D
```
**Площа — це валюта висіння.**

## ❌ Що спростовано остаточно

### Звуження посеред каналу не дає тяги
Інтегрування тиску по стінках (горловина 0,8, V=100 м/с):
- конус звуження: **+9,741 Н вперед**
- конус розширення: **−9,741 Н назад**
- **сума: 0,000 Н**

Загальний доказ: якщо A_вхід = A_вихід, то V₁=V₂ (нерозривність) і p₁=p₂ (Бернуллі) → F_стінки = 0 **тотожно, для будь-якої форми й ступеня звуження**.

З втратами: F = −Δp₀_втрат·A = **−9,5…−25 Н** гальмування.

Універсальний штраф при раптовому розширенні: **(AR−1)²** від корисного напору.
AR=4 → 900 %. AR=1,5625 → 31,6 %.

### Горловина 1:2 запирається
A/A* = 4 → M = 0,1465 → **запирання при 49,8 м/с у трубі**.
- витрата зафіксована на 0,474–0,509 кг/с проти потрібних 0,84–1,19
- тяга падає до **23–34 Н**
- передній вентилятор іде в **обертовий зрив (surge)**
- другий вентилятор **аеродинамічно від'єднується** — через звукову горловину збурення не йдуть проти потоку

### «Другий вентилятор викачує повітря» — механізму не існує
Канал не посудина. Через кожен переріз щосекунди йде однакова маса.
Гірше: **два однакові співобертові ротори без спрямляючого апарата** — другий бачить закрутку, рівну своїй вихідній, і виконує **10–15 % роботи першого**. Як намальовано він — лопатева заглушка.

Розв'язок робочої точки: **~52 Н проти 79,7 Н** для одного добре встановленого вентилятора в тій самій трубі.

| Частка батареї | **~6 %** |

Каталожні цифри EDF — це **пікові режими на 30–60 с**. Тривалий режим — 55–70 % від них.

**Жорстка стеля за тиском:** при PR ≤ 1,25/ступінь один 100-мм канал дає максимум **367 Н**, два ідеальні ступені — **758 Н**. Для 100 кг треба 981 Н. Потужність тут не допоможе.

## ✅ Що підтверджено як правильне в ідеї

- **Канальний вентилятор реально сильніший за відкритий гвинт:** (2σ)^⅓ = **+26 %** при σ=1
- **~50 % статичної тяги канального вентилятора — це розрідження на вхідній губі**, не тиск лопатей. При σ=1,3 — вже 61,5 %. Інтуїція «низький тиск на залізі робить силу» **вірна** — просто прикладена не до тієї поверхні
- **Два ротори на одній осі — це підіймальний вентилятор F-35B** (двоступеневий, зустрічного обертання). Архітектура правильна
- **Зустрічне обертання**: вдвічі більше роботи 2-го ступеня, скасовує момент, знімає втрати на закрутку без спрямляючого апарата
- Труба конструктивно міцна: запас за осьовим навантаженням 250×, за зовнішнім тиском 3–19×

## ⚠️ Окремі вироки, не пов'язані з аеродинамікою

- **Смуга пропускання керування:** ротор EDF на 30–44 тис. об/хв має відгук тяги **0,3–0,6 с**; мультикоптеру треба **< 0,1 с**. 16 модулів **не стабілізують апарат диференціальною тягою**. Не залежить від батареї, турбіни й масштабу
- **Зазор лопать–стінка:** труба має допуск ±0,5 мм + овальність + повзучість; ротор хоче 0,3–0,5 мм → **втрата 10–25 % ККД ступеня**. Дешево не виправити
- **Контейнмент:** ротор запасає 260–730 Дж (≈ 9 мм Parabellum), стінка ПВХ 3 мм поглинає 0,7–12 Дж. **Жоден клас захисту очей EN 166, включно з A (15,5 Дж), не розрахований на уламок 24–42 Дж**
- **Шум:** ~114 дБ(A) на 1 м. За LärmVibrationsArbSchV — **36 секунд на добу** без захисту
- **Теплова загроза — не стиснуте повітря** (реально ~27 °C), а **корпус мотора: 75–250 °C** на пластику з межею 60 °C
