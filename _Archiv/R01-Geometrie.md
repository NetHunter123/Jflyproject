# R01 — Геометрія: довжина, вхід, сопло, пропорції

> Відповідає на питання з ескізу: яка довжина, чи дає звуження на кінці «вихлоп», чи можна два звуження, які пропорції. База — [[R00-Baseline]].

## 🎯 Головне: місія визначає ЗНАК

Це найважливіший висновок етапу. Для двох різних задач потрібна **протилежна** геометрія виходу:

| Мета | Що на виході | Ефект |
|---|---|---|
| **Підйом / висіння** | **Розширення** σ = 1,3 | **+9,1 % статичної тяги** за 57 мм довжини |
| **Швидкість** | **Звуження** σ = 0,80–0,90 | −3,5…−7,2 % статичної тяги, але значно вища стеля швидкості |

σ = A_виходу / A_вентилятора

**Одночасно обидва неможливо.** Спершу вибираємо місію — потім геометрію. Зараз проєкт мовчазно припускає підйом, а геометрія намальована під швидкість.

## 📏 Довжина: усі три варіанти задовгі

Оптимальна довжина каналу **L/D = 0,5–1,0**. Для D=100 мм це **50–100 мм**, а не 60–100 см.

| Варіант | L/D | Втрати на тертя | Мертва вага труби |
|---|---|---|---|
| 100 см | 10 | 11,2 % напору | 1,36 кг = 13,3 Н |
| 80 см | 8 | ~9 % | 1,09 кг |
| 60 см | 6 | ~6,7 % | 0,82 кг |
| **10–13 см** | **1,0–1,3** | **~0,7–1,3 %** | **~0,15 кг** |

При тязі 61–72 Н метрова труба з'їдає **20 % тяги лише на те, щоб нести саму себе**.

> **Рішення:** розділити дві різні речі — **канал** (де йде швидкий потік) і **корпус** (де живуть батарея й електроніка).
> Канал робимо коротким (10–13 см). Корпус може бути будь-якої довжини — він легкий, обтічний і **не є частиною газового тракту**.

## 👃 Ніс: загострений — так, але не там

На ескізі ніс звужується **у вістря на вході**. Для повітрозабірника це неправильно і коштує найдорожче з усіх помилок геометрії.

**Чому:** близько **50 % статичної тяги канального вентилятора — це розрідження на вхідній губі**. Гострий край це розрідження не тримає: потік зривається, утворюється vena contracta.

| Вхід | Коефіцієнт втрат K | Наслідок |
|---|---|---|
| Прямий зріз / вістря | **0,50** | втрата ~24 % тяги; реальний виграш каналу падає з +26 % до +5–12 % |
| Закруглена губа r/D ≥ 0,2 | **0,04** | повертає ~2 000 Па з 4 425 Па корисного напору, **+31 % ККД каналу** |

Для D=100 мм: **радіус губи 20–25 мм**.

> ✅ **Ваше вістря має право на життя — але в центрі, а не по краю.**
> Саме так влаштований кожен турбовентиляторний двигун: гострий **кок (spinner)** стоїть по осі, а вхід — це **кільце** навколо нього із закругленою губою. Ви отримуєте і гострий ніс, і правильний вхід.

## 🚀 Сопло на виході: так, це працює

**Відповідь на «чи дасть вихлоп»: дасть — і це єдине місце в машині, де звуження законне.**

| σ = A_вих/A_вент | Втрата статичної тяги |
|---|---|
| 0,90 | −3,5 % |
| 0,85 | −5,3 % |
| 0,80 | −7,2 % |
| 0,50 | **0 % виграшу каналу взагалі** (як відкритий гвинт) |
| 0,25 | **−21 %** — гірше, ніж зовсім без труби |

Серійна практика EDF: **77–90 %**. Schübeler DS-51 має рівно 77,2 %.

**Але треба розуміти, що саме купується.** Сопло **не збільшує** статичну тягу — воно її трохи зменшує. Воно підіймає **швидкість струменя**, а це має сенс лише в польоті:

- стеля швидкості: **365 → 662 км/год** (сопло + закруглена губа)
- максимальна швидкість крилатого апарата: 247 → **~300–355 км/год**

> ⚠️ Важлива деталь вимірювання: σ рахується від **кільцевої площі вентилятора** (без втулки мотора), а не від внутрішнього діаметра труби. Втулка перекриває 25–40 % перерізу — якщо рахувати від труби, помилитесь у півтора раза.

## ⛔ Два звуження: середнє однаково зайве

Якщо є і середнє звуження, і сильніше кінцеве, то **мінімальний переріз — на виході**. Середня горловина перестає бути горловиною і стає просто ділянкою, де потік розганяється й гальмується назад — за вашу ж потужність.

Дифузор між нею і соплом не робить нічого корисного: він відновлює тиск, який ви ж і витратили.

**Залишаємо одне звуження — на виході. Середню частину робимо прямою.**

## 📐 Пропозиція геометрії v1 (D = 100 мм)

```
 ← 20-25 →← 40-60 →←  30  →
 ╭─────╮
(  губа ) [ротор+статор] [сопло]      σ = 0,85 → d_вих = 92 мм
 ╰─────╯                              σ = 0,80 → d_вих = 89 мм
    ▲                                 (розширення σ=1,3 → d = 114 мм, +57 мм)
    кок по осі
```

| Елемент | Розмір | Примітка |
|---|---|---|
| Радіус вхідної губи | 20–25 мм | r/D = 0,2–0,25 |
| Ділянка входу | ~25 мм | |
| Секція вентилятора | 40–60 мм | ротор + спрямляючий апарат |
| Сопло до σ=0,85 | ~30 мм | звуження не зривається, може бути коротким |
| **Канал разом** | **110–130 мм** | L/D ≈ 1,1–1,3 |
| Альтернатива для висіння | дифузор +57 мм | 7° півкута, σ=1,3, **+9,1 % тяги** |

## 🔧 Про мотор усередині (коротко, повністю — в R03)

Втулка мотора перекриває **25–40 % перерізу**. Це не «неефективно» — це просто означає, що всі розрахунки тяги за повним діаметром труби завищені на цю частку. Варіанти обходу (rim-drive, винесений вал, тонка втулка) — окремий етап **R03**.

## 📋 Підсумок етапу

1. **Довжина 60–100 см зайва в 6–10 разів.** Канал = 10–13 см; решта — легкий корпус поза газовим трактом
2. **Вістря на вході — найдорожча помилка.** Переносимо його в центр як кок, край робимо закругленим r ≥ 20 мм. Це найвигідніша зміна в усьому проєкті
3. **Сопло на виході законне і працює** — але дає швидкість, а не тягу. σ = 0,80–0,90, не більше
4. **Середнє звуження прибираємо** — при наявності кінцевого сопла воно безглузде вдвічі
5. **Спершу вибрати місію**: підйом → розширення на виході; швидкість → звуження. Знаки протилежні
